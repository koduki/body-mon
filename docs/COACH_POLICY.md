# ボディメイク専門コーチ方針

## 目的

チャットの流暢さだけに判断を任せず、端末内KPIを、筋力と回復を守りながら脂肪を
減らすための一貫した助言へ変換する。判定ロジックは
`CoachAssessmentEngine`、Geminiへの専門家指示は
`BodyRecompositionCoachPolicy`を正本とする。

## 処理境界

1. 端末内の週次KPIを決定論的なコーチシグナルへ変換する。
2. Geminiは従来の送信契約と会話メモリーだけで回答する。
3. Geminiの応答後に、端末内で専門家判定・根拠・今週の一手を合成する。

新規KPI、減量開始日、コーチシグナルはGeminiへ送信しない。専門家方針を追加しても、
外部送信する健康データ項目は増やさない。

## 応答形式

- **評価:** 順調、要観察、調整推奨、判定保留
- **根拠:** 観測できたKPI。BIAとウェアラブル由来値は出所を明記
- **今週の一手:** 優先度順に最大2件
- **判定の限界:** 欠測、測定品質、筋力パフォーマンス未取得を明記

会話から得た習慣は個別化に利用するが、習慣と数値の因果関係は断定しない。
不明点は断定せず、先に確認質問を最大2件出す。

## 低脂質ダイエット

食事方針は低脂質ダイエットとする。助言は食事内容、運動量、摂取と活動の
バランス、PFC（グラムとエネルギー比）から行う。脂質エネルギー比15〜25%を
運用目安とし、30%超は出どころを確認する。たんぱく質は体重1kgあたり1.6gを
下回らないかを確認する。極端な脂質カットや摂取ゼロは提案しない。

## 端末内の運用ルール

| シグナル | 判定 | 主な対応 |
|---|---|---|
| 28日減量ペース0.3〜0.7%体重/週 | 順調 | 現行方針を維持 |
| 0.7%体重/週超 | 調整推奨 | 減量を強めず、疲労・空腹・筋力を確認 |
| BIA除脂肪量が-0.20kg/週以下 | 要観察 | 筋肉減少と断定せず、パーソナルで重量・回数を比較 |
| 朝トレ継続率80%以上 | 順調 | 習慣維持として評価 |
| 朝トレ継続率70%未満 | 調整推奨 | 負荷より短い最低メニューで実施日を戻す |
| 歩数が減量前平均の90%未満 | 要観察 | 推定消費量ではなく通常歩数へ戻す |
| 7時間以上の主睡眠が3日以下 | 要観察 | 減量・運動強化より睡眠機会を優先 |
| 睡眠中心拍が直前21日平均より5bpm以上高い | 要観察 | 診断せず、疲労・睡眠・飲酒・体調を確認 |
| 同時刻帯の体組成測定が70%未満 | 要観察 | 寝起き・トイレ後・飲食前・同程度の服装へ統一 |
| たんぱく質が体重1kgあたり1.6g未満（5日以上の記録） | 要観察 | 減量強化より、記録済み食事のたんぱく質を確認 |
| 脂質エネルギー比30%超（5日以上の記録） | 要観察 | 調理油・間食など出どころを確認してから脂質を調整 |
| 脂質エネルギー比15〜25% | 順調 | 低脂質の運用目安内 |

これらはアプリ内で優先順位を一貫させるための運用閾値であり、診断基準ではない。
特にBIA除脂肪量と睡眠中心拍は単独で結論を出さない。

## 筋力維持の扱い

Health Connectの`Other Workout`は朝の5分ルーティンとして識別し、軽い筋トレと
有酸素運動の両方として評価する。その実施日数を一般的な筋トレ日数の代わりに
朝トレ継続KPIへ使うが、筋力維持の証明にはしない。Health Connectから重量・回数・
RIRを取得できないため、月1回のパーソナルで同じ種目の重量と回数を比較する。
減量ペースが速い、またはBIA除脂肪量が下降している場合、この定点確認を最優先の
追加情報とする。

## 安全境界

- 医療診断、疾病推測、服薬指示をしない。
- 活動消費カロリーや基礎代謝から摂取量・赤字量を逆算しない。
- 食事記録がある日だけ摂取カロリーとPFCを観測値として扱う。欠測日を0kcalとしない。
- 食事回数を栄養レコードの件数や取得時刻から推定しない。欠測日を0食としない。
- 推定エネルギー収支は参考値であり、減量成否の判定には使わない。
- データ不足や矛盾時は結論を保留する。
- 症状や持続する異常については、アプリ内KPIで診断せず専門家への相談を案内する。

科学的根拠は [`KPI_DESIGN.md`](KPI_DESIGN.md) と共通とする。
